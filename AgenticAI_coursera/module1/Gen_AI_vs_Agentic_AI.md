# Generative AI (Gen AI) vs Agentic AI

## Quick Definition

### Generative AI (Gen AI)

Generative AI focuses on **creating content** based on user prompts.

Examples:

* ChatGPT/Copilot answering questions
* Generating code
* Writing emails
* Creating images, videos, and documents

**Input → Generate Output**

```
User Prompt
     ↓
   Gen AI
     ↓
Generated Response
```

***

### Agentic AI

Agentic AI goes a step further. It can **plan, decide, take actions, use tools, and work toward a goal with minimal human intervention.**

Examples:

* Booking meetings automatically
* Reading emails and responding
* Creating tickets in Jira
* Analyzing data and generating reports
* Multi-step task automation

**Goal → Plan → Act → Observe → Improve**

```
Goal
 ↓
Plan
 ↓
Use Tools
 ↓
Take Action
 ↓
Check Result
 ↓
Repeat Until Goal Achieved
```

***

# Key Differences

| Aspect          | Generative AI                      | Agentic AI                    |
| --------------- | ---------------------------------- | ----------------------------- |
| Purpose         | Generate content                   | Achieve goals                 |
| Output          | Text, code, image, video           | Actions + decisions + outputs |
| Reasoning       | Limited to prompt                  | Multi-step planning           |
| Memory          | Usually short conversation context | Can maintain state and memory |
| Tool Usage      | Optional                           | Core capability               |
| Autonomy        | Low                                | High                          |
| Decision Making | User-driven                        | AI-driven                     |
| Workflow        | Single-step                        | Multi-step                    |

***

# Real World Example

## Gen AI Example

**Prompt:**

> Create a React login form.

**Result:**

* Generates React code.

After that, the user must:

* Create file
* Test code
* Deploy application

AI only generates content.

***

## Agentic AI Example

**Goal:**

> Build and deploy a React login page.

Agentic AI might:

1. Generate React code
2. Create project files
3. Install dependencies
4. Run tests
5. Fix errors
6. Build application
7. Deploy to server
8. Send deployment report

AI performs multiple actions automatically.

***

# Characteristics of Agentic AI

An Agent typically has:

### 1. Goal

```text
Generate monthly sales report
```

### 2. Planning

```text
Step 1: Collect data
Step 2: Analyze
Step 3: Create report
Step 4: Send email
```

### 3. Tool Usage

Uses:

* Database
* APIs
* Browser
* Email
* File systems

### 4. Memory

Remembers:

* Previous actions
* User preferences
* Current task state

### 5. Reflection

Checks:

```text
Did the task succeed?
If not, retry.
```

# Interview Answer (Short)

> Generative AI is designed to create content such as text, code, images, and documents based on user prompts. Agentic AI extends Generative AI by adding planning, reasoning, memory, decision-making, and tool usage capabilities, enabling it to autonomously perform multi-step tasks and achieve goals with minimal human intervention.

### One-line Difference

> **Gen AI generates content, whereas Agentic AI generates content and takes actions to accomplish objectives.** ✅
